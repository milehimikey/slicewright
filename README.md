# Slicewright

Slicewright is an agentic software development lifecycle built on event
modeling. Agents propose slices of behavior, humans ratify them, and machines
check that the implementation stays true to what was ratified — using
[`em`](https://www.npmjs.com/package/@milehimikey/em) and `em-sdd-bridge` as
the toolset, with the Meridian Goods demo as the proof artifact.

Status: pre-release.
