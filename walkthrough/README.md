# Walkthrough

The locked, presenter-ready script for the Meridian Goods walkthrough,
pinned to `em 1.8.0` / `em-sdd-bridge 0.4.0`:

- [`script.md`](./script.md) — the ~25-minute full walkthrough, beat by
  beat: what the audience sees, the exact invocation, the real captured
  output, and what it proves.
- [`teaser-5min.md`](./teaser-5min.md) — the compressed 4-beat arc for a
  5-minute slot.
- [`presenter-checklist.md`](./presenter-checklist.md) — everything to
  verify before going live: pinned versions, repo state, the spec-kit
  scaffold, tags, the seeded-divergence checkpoint, and known Q&A
  landmines.

The command sequence itself lives in the `meridian-goods` repository,
checkpointed as a series of `walkthrough/*` tags — one tag per beat, each
reproducible from a clean clone.
